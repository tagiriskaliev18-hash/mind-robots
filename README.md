# Mind

Одна фигура в темноте. Скролл листает заранее отрендеренную последовательность Apptronik Apollo: силуэт, визор, плечевой привод, торс, общий план снизу. Подписи стоят на сетке, выноски привязаны к точкам, которые Blender спроецировал в каждом кадре. Ноябрь 2026. Язык — русский.

Точка входа: `index.html`. Кадры: `frames/desk` и `frames/phone` (WebP, сначала низкое разрешение, затем полное). Лицензия модели: `APOLLO-LICENSE` (Apache-2.0, © 2024 Apptronik, MuJoCo Menagerie). Шрифты Geist и Geist Mono лежат в `fonts/` с кириллическими подмножествами.

## Как открыть

```bash
python3 -m http.server 47321
```

Дальше `http://127.0.0.1:47321/`. Адреса относительные, в корне `.nojekyll`.

`prefers-reduced-motion` оставляет последний кадр и колонку `#reading`. Это настройка человека, не ширина экрана. На узком экране pixel ratio ограничен 1.5, на широком — 2.
