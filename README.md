# Современные роботы — моушн-лендинг (Mind style)

Одностраничный сайт на русском: кто такие современные роботы, как они устроены,
как их подключать, какие AI/VLA-модели ими управляют и с чего начать новичку.

## Как открыть

- Самый простой путь: двойной клик по `index.html` — всё работает локально,
  без интернета (библиотеки и шрифты лежат в репозитории).
- Через локальный сервер (рекомендуется для точной проверки):
  `python -m http.server 8777` в этой папке → http://127.0.0.1:8777/

## Структура

```
index.html            разметка и весь контент
css/style.css         дизайн-система, секции, адаптив
css/fonts.css         @font-face для вендоренных шрифтов
js/main.js            Lenis + GSAP/ScrollTrigger: reveal, пин-галерея, счётчики, FAQ
js/hero.js            Three.js: абстрактное «нейронное ядро» в hero
vendor/               gsap, ScrollTrigger, lenis, three (локальные копии)
media/fonts/          Inter + JetBrains Mono (latin + cyrillic, woff2)
media/favicon.svg     иконка
media/og.svg          обложка для шеринга
```

## Что внутри по моушну

- Smooth scroll (Lenis), синхронизированный со ScrollTrigger.
- Прелоадер со счётчиком и переходом в hero-таймлайн.
- Пословная анимация заголовков, reveal-секции, параллакс аврор и сетки.
- Горизонтальная пин-галерея классов роботов (на мобильных — свайп).
- Scroll-driven отрисовка SVG-контура управления с бегущей точкой.
- Счётчики цифр, бесконечный marquee, 3D-тилт карточек, аккордеон FAQ.
- WebGL-hero с деградацией в CSS-градиент; полный respect `prefers-reduced-motion`.

## О фактах

Контент опирается на публикации разработчиков (Figure, Physical Intelligence,
NVIDIA, Google DeepMind, Boston Dynamics, Unitree), статьи arXiv и отчёты IFR
World Robotics. Числа приведены с указанием источника и года — перед
использованием в проектных решениях их стоит перепроверить по первоисточникам.
