# Mind

Один непрерывный фильм о современных роботах. Кадр — это страница: видео коридора и фотографии на весь экран, текст внутри темноты кадра. Язык — русский. Ноябрь 2026.

Точка входа: `index.html`. Счёт движения: `ledger.json` (камера идёт вперёд по Z, вверх — только финал).

## Как открыть

```bash
python3 -m http.server 47321
```

Дальше `http://127.0.0.1:47321/`. Адреса относительные, в корне лежит `.nojekyll`, папка готова к GitHub Pages.

## Просмотр

- Сначала телефон 390×844, затем 1440×900. Это один и тот же фильм, не две вёрстки.
- Скролл двигает камеру и смену кадров на обоих размерах. Видео в начале без звука, зациклено, под ним постер.
- `prefers-reduced-motion` оставляет те же полноэкранные кадры и текст, без закрепления скролла. Это настройка человека, не мобильная ширина.
- Шрифты с кириллицей лежат в репозитории. Кадры — съёмка вымышленной машины. Цифры — из публичных сообщений компаний на ноябрь 2026. Герцы — порядок величин, не спецификация одной модели.
