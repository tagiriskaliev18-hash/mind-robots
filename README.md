# Mind

Редакционный сайт о современных роботах: что они такое, как устроена петля «чувствует → думает → действует», как к ним подключаются и какие модели на них стоят. Ноябрь 2026. Язык — русский.

Точка входа: [`index.html`](index.html)

## Как открыть

Статический сайт, бэкенда нет. Все адреса относительные, поэтому страница работает и из корня репозитория, и как проект GitHub Pages.

```bash
python3 -m http.server 47321
```

Дальше открыть `http://127.0.0.1:47321/`. Файл `index.html` можно открыть и напрямую.

## Заметки к просмотру

- Вёрстка проверена на 1440×900 и 390×844.
- Sense → Think → Act — одна закреплённая сцена: слово, кадр и частота меняются по скроллу, это не три карточки. На ширине от 960px блок платформ листается горизонтально.
- Движение на GSAP и ScrollTrigger, файлы лежат в `js/vendor/`. При `prefers-reduced-motion: reduce` закрепление снимается, все три такта и все платформы идут обычным вертикальным потоком.
- Шрифты с кириллицей самодостаточные (OFL): Cormorant Garamond, Manrope, Unbounded, JetBrains Mono.
- Кадры — оригинальные съёмки вымышленной машины, не пресс-фото компаний. Цифры в тексте взяты из публичных сообщений Figure, Boston Dynamics, 1X, Unitree, Tesla, Physical Intelligence и NVIDIA на ноябрь 2026. Частоты в петле — типичный порядок величин, не спецификация конкретной модели.
- Публичный адрес этого репозитория здесь не задаётся: страница готова к публикации, но сама по себе URL не публикует.
