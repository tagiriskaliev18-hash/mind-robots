# Mind — Apollo, живая модель

Интерактивная страница с моделью Apptronik Apollo. Камера орбитирует непрерывно. Вкладки двигают камеру и разводят детали на пружинах. Это не покадровый скролл.

Модель: Apptronik Apollo, Apache-2.0, © 2024 Apptronik, via MuJoCo Menagerie. Текст лицензии — в `APOLLO-LICENSE`.

## Запуск

```bash
python3 -m http.server 47321
```

Откройте http://127.0.0.1:47321

Страница открывается собранным роботом и крупным заголовком за ним. Заголовок уходит, как только выбрана вкладка: Голова, Руки, Корпус, Привод, Разбор, Сборка. Тяните модель, чтобы повернуть. На телефоне — жест двумя пальцами для масштаба. Колесо страницы ведёт по разделам, затем к тексту.

`prefers-reduced-motion` останавливает орбиту и пружины: вкладки переключают кадр сразу.
